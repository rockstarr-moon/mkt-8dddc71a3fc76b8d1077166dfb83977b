# Rockstarr AI plugin marketplace

This repository is a tokenized plugin marketplace for Rockstarr AI. It is
managed automatically — please do not edit by hand.

## Installing plugins in Cowork

1. Paste this repository's URL into **Cowork → Settings → Plugins →
   Add Marketplace** and install the plugin you want.
2. **On Personal plans**, open the menu attached to the marketplace
   name, flip **Sync updates** on, and authorize GitHub when prompted.
   After that, new releases arrive automatically. Team and Org plans
   don't need this step.

### Fallback: manual upload

Each release is also packaged as [`downloads/<plugin>.zip`](./downloads)
at a stable URL in this repo. If GitHub authorization isn't an option,
download the matching zip and upload it via **Settings → Plugins**
(upload-a-plugin flow).

See https://github.com/rockstarr-moon for the main org.
